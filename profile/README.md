# 8bit

**Business Solutions**

Desarrollamos soluciones de gestión empresarial basadas en **Odoo**, con módulos personalizados e integraciones adaptadas a los procesos de cada empresa.

## Qué hacemos

- Desarrollo de módulos personalizados para Odoo.
- Integración de procesos y herramientas de gestión.
- Implementación, adaptación y evolución de soluciones empresariales.

## Nuestros repositorios

Organizamos el trabajo por proyecto y documentamos cada repositorio con su propósito, dependencias e instrucciones de instalación. Algunos proyectos y sus catálogos son privados y están disponibles para sus colaboradores autorizados.
